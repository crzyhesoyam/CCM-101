
| Infrastructure Component | AWS | Microsoft Azure | Google Cloud Platform |
|---|---|---|---|
| Compute | EC2 (Elastic Compute Cloud) | Virtual Machines | Compute Engine |
| Storage | S3 (Simple Storage Service) | Blob Storage | Cloud Storage |
| Networking | VPC (Virtual Private Cloud) | Virtual Network (VNet) | VPC (Virtual Private Cloud) |
| Identity and Access Management (IAM) | AWS IAM | Azure Active Directory (Entra ID) | Cloud IAM |

1. **Which cloud provider offers the broadest range of services?**
   AWS is generally considered to have the broadest range of services, since it was the first major provider and has the largest catalog of specialized tools.

2. **Which cloud platform would you recommend for an organization that primarily uses Microsoft products? Why?**
   Azure, since it integrates natively with Windows Server, Active Directory, and Microsoft 365.

3. **Which platform is widely recognized for AI, ML, and Kubernetes services?**
   GCP — it created Kubernetes and is well-regarded for its AI/ML tools like Vertex AI and TensorFlow support.

4. **What similarities did you observe among the three cloud providers?**
   All three offer compute, storage, networking, and IAM services; all support scalability, pay-as-you-go pricing, and global data center availability.
