
# Google Cloud Platform (GCP)

## Brief Overview
Google Cloud Platform (GCP) is Google's suite of cloud computing services, built on the same infrastructure Google uses for its own products (Search, YouTube, Gmail). GCP is especially known for strengths in data analytics, machine learning, and Kubernetes/container orchestration (which Google originally created).

## Global Infrastructure
GCP infrastructure is organized into **regions** and **zones**. With Google Cloud, you can deploy workloads across 43 global regions and 130 zones for high performance foundational and agentic workloads at scale, connected through Google's private global network spanning 200+ countries and territories. A typical region consists of three or more zones housed in three or more physical data centers, allowing workloads to remain available even if one zone experiences an outage.

## Cloud Management Console
The **Google Cloud Console** is a web-based GUI for managing GCP resources, projects, billing, and IAM roles. It also provides direct access to Cloud Shell (a built-in command-line environment) and integrates tightly with tools like BigQuery and Vertex AI.

## Four (4) Core Services
1. **Compute Engine** – Scalable virtual machine instances.
2. **Cloud Storage** – Object storage for unstructured data.
3. **Cloud IAM** – Identity and access management for GCP resources.
4. **BigQuery** – Serverless, highly scalable data warehouse for analytics.

## Three (3) Advantages
1. **Leading data analytics and AI/ML capabilities** – tools like BigQuery, Vertex AI, and TensorFlow integration are industry-leading.
2. **Best-in-class Kubernetes support** – Google Kubernetes Engine (GKE) is the most mature managed Kubernetes offering, since Google created Kubernetes.
3. **Competitive, transparent pricing** – often cited for simpler, more predictable pricing models and sustained-use discounts.

## Typical Enterprise Use Cases
- Data-heavy organizations needing large-scale analytics (BigQuery)
- AI/ML research and high-performance computing workloads
- Container-based, Kubernetes-native application deployments
- Startups and tech companies wanting Google-grade infrastructure at competitive cost
