
# Microsoft Azure

## Brief Overview
Microsoft Azure is Microsoft's cloud computing platform, offering a comprehensive set of cloud services for building, deploying, and managing applications. It's particularly known for deep integration with Microsoft's enterprise software ecosystem — Windows Server, Active Directory, and Microsoft 365.

## Global Infrastructure
Azure organizes infrastructure into **geographies**, **regions**, and **availability zones**. Azure provides over 70 regions globally, located across many different geographies, where each geography represents a data residency boundary such as the United States or Europe. Microsoft's global cloud infrastructure includes more than 70 regions, over 400 datacenters worldwide, and over 190 edge sites, giving it the broadest geographic footprint of any major cloud provider by region count.

## Cloud Management Console
The **Azure Portal** is a web-based, unified console for creating, managing, and monitoring Azure resources. It offers a customizable dashboard, integrated cost management, and access to Azure CLI, PowerShell, and Cloud Shell directly in the browser.

## Four (4) Core Services
1. **Azure Virtual Machines** – On-demand, scalable compute resources.
2. **Azure Blob Storage** – Object storage for unstructured data.
3. **Azure Active Directory (Microsoft Entra ID)** – Identity and access management, tightly integrated with enterprise directories.
4. **Azure SQL Database** – Fully managed relational database service.

## Three (3) Advantages
1. **Best-in-class integration with Microsoft products** – seamless connection with Windows Server, Active Directory, Microsoft 365, and Dynamics 365.
2. **Strong hybrid cloud capabilities** – tools like Azure Arc and Azure Stack let enterprises blend on-premises and cloud infrastructure.
3. **Extensive compliance certifications** – favored by government and regulated industries for its broad compliance coverage.

## Typical Enterprise Use Cases
- Organizations already running Microsoft infrastructure (Windows Server, AD, Microsoft 365) migrating to the cloud
- Hybrid cloud deployments combining on-prem and cloud resources
- Enterprise application modernization (e.g., .NET apps)
- Government and highly regulated industries needing strict compliance
