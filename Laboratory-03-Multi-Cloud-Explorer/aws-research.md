
# Amazon Web Services (AWS)

## Brief Overview
Amazon Web Services (AWS) is the cloud computing arm of Amazon, offering over 200 fully featured services from data centers worldwide, including compute, storage, databases, networking, AI/ML, and analytics. It is widely regarded as the market leader in cloud infrastructure, serving millions of customers across nearly every industry.

## Global Infrastructure
AWS organizes its physical infrastructure into **Regions**, **Availability Zones (AZs)**, and **Edge Locations**. Each AWS Region is a physical geographic area that consists of a minimum of three isolated and physically separate Availability Zones within a geographic area, each with independent power, cooling, and physical security, connected via redundant, ultra-low-latency networks. As of 2026, AWS maintains numerous global regions across North America, South America, Europe, Asia Pacific, and the Middle East, serving over a million active customers in more than 190 countries, with roughly 38 regions and 120 Availability Zones worldwide, and continues expanding into new regions like Mexico, Saudi Arabia, and Taiwan.

## Cloud Management Console
The **AWS Management Console** is a web-based interface for accessing and managing AWS services. It lets users provision resources, monitor usage, set billing alerts, configure IAM permissions, and interact with services either through the GUI, the AWS CLI, or SDKs.

## Four (4) Core Services
1. **Amazon EC2 (Elastic Compute Cloud)** – Resizable virtual server (compute) instances.
2. **Amazon S3 (Simple Storage Service)** – Scalable object storage for any amount of data.
3. **Amazon RDS (Relational Database Service)** – Managed relational databases (MySQL, PostgreSQL, etc.).
4. **AWS IAM (Identity and Access Management)** – Fine-grained access control to AWS resources.

## Three (3) Advantages
1. **Largest service catalog and market share** – broadest range of tools, from basic compute to advanced AI/ML.
2. **Mature global infrastructure** – most extensive network of regions and AZs, reducing latency and improving fault tolerance.
3. **Strong ecosystem and community support** – extensive documentation, certifications, third-party integrations, and marketplace tools.

## Typical Enterprise Use Cases
- Hosting large-scale, high-traffic web applications and e-commerce platforms
- Big data processing and analytics pipelines
- Disaster recovery and backup solutions
- Enterprise-grade hybrid cloud deployments
